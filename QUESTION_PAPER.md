## Case Study: OpenStreetMap UX and Functionality Improvement Challenge

OpenStreetMap provides an interactive map and geographic information about locations, roads,
businesses and points of interest. Its website supports map exploration and location-related queries.
Students must investigate the existing website rather than assume that it has a particular usability
defect.

Students are required to act as a member of a web development team, benchmark the existing user
experience, and develop an improved, focused web application tailored to a specific user group.

**Tasks:**
1. Examine the existing website and document its relevant features and workflow.
2. Identify a specific user difficulty, missing capability or opportunity for improvement.
3. Define a clear problem statement and propose an innovative solution.
4. Develop a responsive web application using HTML5, Tailwind CSS and JavaScript.
5. Integrate form handling, meaningful JavaScript events, Fetch API and JSON data handling.
6. Maintain the source code in GitHub and deploy the working application.

**Important:** Students are not required to reproduce the complete OpenStreetMap platform. Select one
workflow and create a focused, functional improvement. Any identified limitation must be supported
by your own observations or testing.
